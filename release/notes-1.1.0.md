TWD Access makes The Walking Dead: The Telltale Definitive Series playable by ear, through your screen reader (NVDA, JAWS and others) or Windows' own voice.

## What's new in 1.1.0

- A new setting, `streaming`, for streaming or recording with OBS. On Windows 11, TWD Access opens in Windows Terminal, so OBS's Application Audio Capture could not find `TWDAccess.exe`, the program that plays the mod's beeps and tones.
- Set `streaming = true` in the game folder's `TWDAccess\settings.txt`. TWD Access then opens in a window of its own, called "TWD Access".
- In OBS, add an Application Audio Capture and pick the window marked `[TWDAccess.exe]`.
- The setting is off by default. It takes effect the next time TWD Access starts.

## Install or update

1. Download `TWDAccess-1.1.0.zip` and unzip it anywhere. To update, unzip it over your old TWDAccess folder. Your settings are kept, since they live in the game folder.
2. Run `TWDAccess.exe` each time you play. It installs the mod into the game folder and starts the game through Steam.
3. On the title screen, press Enter.

You don't need to install anything else: .NET is built in. `README.txt` in the zip lists the keys and settings, and how to remove the mod.

## Requirements

- Windows 10 or 11, 64-bit.
- The game on Steam.
